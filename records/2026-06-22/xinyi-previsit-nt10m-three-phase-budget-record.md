## 核心設計結論

每年新臺幣 10,000,000 元、三年合計新臺幣 30,000,000 元可支撐一條清楚的三期 evidence-building path：第一期 / 第一年 10,000,000 元建立專利邊界、IRB、資料治理、MVP 與 shadow validation；第二期 / 第二年 10,000,000 元推進受控前瞻試辦與 HIS/FHIR/pended-order workflow UAT；第三期 / 第三年 10,000,000 元完成外部驗證、法規/IP gap assessment、健康經濟與擴散前證據包。

本期 operating scope 聚焦單院、泌尿科優先、候診檢查候選審閱 workflow、有限 HIS/FHIR/pended-order 串接、前瞻 pilot、外部驗證與法規/IP gap assessment。完整商用醫材、多科別、多院區、正式 TFDA/FDA 送件、PCT/美國專利 prosecution、長期維運與商業客服，形成下一階段 production governance、商轉資金與醫材送件路徑。

專利揭露書的 claim path 可整理為：

```text
生命徵象 + 問卷文字
-> AI 候選判斷
-> 醫師 / 護理師提前審閱
-> 醫師核准檢查
-> HIS / LIS / RIS / 檢驗影像流程
```

醫師核准權是本案的臨床治理核心。`忠孝信義深耕計畫_修改260618.docx` 的經費格式可直接轉為 AI 候診系統經費表：逐項列出單價、單位、數量、合計與支用說明，並沿用臨時護理 / 醫檢人員每小時 534 元、行政人員每小時 415 元、審查費 / 出席費 2,500 元、調查訪問費 100 元、資料處理費 100 元等計價基準。

## 六、proposal design upgrades

第一，KPI 同時涵蓋流程效率與醫療安全。建議納入候選提示 false positive burden、醫師 override rate、補問率、候選形成至審閱時間、醫師核准 / 駁回 / 補問留痕率、叫號後新增檢查比例、病人因提前檢查對正式看診節奏造成的時間影響。專利文件既有醫師核准、駁回、補問、回到一般候診、完成檢查等狀態，適合直接轉為 KPI。

第二，本案語言維持 review-support workflow 與 physician-approved order。系統定位在候選提示、支持摘要、醫護提前審閱、醫師核准與 intent log；法規定位透過 FDA CDS guidance、TFDA AI/ML 醫療器材軟體查驗登記技術指引與第三期 gap assessment 管理。([U.S. Food and Drug Administration][5])

第三，醫師 intent 與留痕是系統核心。CMS 對 lab test order 的公開說明指出，clinical diagnostic test order 的 medical record 需記錄 ordering intent，並有足夠資訊支持合理性與必要性。台灣實務依院內規範與法規處理；產品設計可採「AI candidate -> physician-approved order -> intent log」作為核心資料路徑。([Centers for Medicare & Medicaid Services][6])

第四，建立 clinical rule owner 制度。每一個科別、每一類檢查候選都有臨床 owner。門檻、prompt、候選規則與排序調整由 clinical owner、AI team、IT/security owner 共同留痕。每季至少做一次錯誤案例審查，記錄規則核准者、上線版本、false-positive burden 與漏提示案例。

第五，補助書揭露驗證與查核方式，模型 know-how 作為營業秘密管理。模型架構、prompt chain、embedding、RAG、ranking/reranking、候選分數、門檻、權重、科別 mapping、API payload、schema、deployment topology 等內容，進入 trade-secret stewardship 與 vendor/academic contribution boundary。

第六，清楚處理發明人、申請人、廠商貢獻邊界。專利揭露書列出 Jason、許醫師、吳老師、Tomi / 專利事務所、NYCU 或其他指定單位；與慧誠智醫等廠商合作時，將公司背景資料與 NYCU / Jason / 多寶的發明貢獻分層紀錄。此邊界支撐發明人認定、職務發明、技轉分潤與後續合作授權。

第七，每年 10,000,000 元，三年合計 30,000,000 元 operating scope 直接支撐可驗證的臨床 workflow pilot。計畫產出臨床證據包、法規定位、資安驗證、技轉資料包；下一階段銜接商轉、醫材、院內資訊系統擴充或廠商合作資金。

## 一頁結論

本次會議將華山場域的高齡者肌少症與跌倒風險深耕計畫，收斂為一條可驗證、可部署、可擴散的智慧健康服務線。計畫的核心價值是建立「量測、分流、衛教、導流、追蹤」的閉環照護流程，讓社區高齡者在篩檢後取得清楚的風險辨識、個人化回饋、照護導流與持續追蹤。

智慧互動終端與機器人適合擔任衛教、導覽、流程說明、互動問答、安全提醒與現場引導角色。Computer vision 影像量測可作為選配或後續驗證模組，於設備條件、場域安全、人員配置與模型效度確認後納入擴充。這個定位讓機器人保有科技亮點，也讓計畫的第一版交付保持穩定、可驗收、可維護。

模型驗證的核心是建立清楚的 ground truth。計畫可用握力、BIA / ASMI、SPPB、SARC-F、小腿圍、跌倒史、疼痛、共病、用藥、STS5、TUG、步態與人口學變項形成可審查的資料層，再評估影像特徵與功能性指標對肌少症或跌倒風險的預測力。第一年收案設計應納入陽性與陰性個案，並保留年齡、性別、族群來源、場域來源與 reference-standard label，支撐模型信效度、外部驗證與 proposal KPI。

健康艙適合成為肌少症計畫中的固定量測與資料整合 anchor。健康艙承擔基礎生理量測、基本人口學資料、BIA / 身高體重 / 血壓 / 血糖血脂 / 握力或外部匯入資料、互動問卷、QR/report、雲端資料流與 HIS/FHIR-ready 後續資料流；智慧互動終端承擔現場溝通與衛教；雲端平台整合量測、問卷、LINE / APP、Dashboard 與臨床導流，形成可查核的紅黃綠燈分流與年度 KPI evidence。

## 第一原理分析

### 1. 計畫主體是閉環照護服務線

本計畫的核心交付是高齡者肌肉健康與跌倒風險的閉環照護服務線。社區整合性篩檢作為入口，AI 與功能性量測協助風險辨識，智慧互動終端與 LINE / APP 支援衛教與追蹤，健康服務中心與聯醫多專業團隊承接紅黃綠燈導流，年度 KPI evidence 回饋到模型、流程與照護設計。

可執行架構分成四層：

| 層級 | 內容 | proposal value |
| --- | --- | --- |
| 量測層 | STS5、TUG、步態、握力、小腿圍、BIA、SARC-F、SPPB、跌倒史、疼痛、共病、用藥、vital signs | 建立低負擔且可驗證的肌少症 / 跌倒風險資料來源 |
| 資料層 | 雲端平台、資料庫、去識別化、FHIR / HIS-ready mapping、QR code / PDF 報告、Dashboard | 支援年度查核、追蹤、導流與跨系統交接 |
| 互動層 | LINE、APP、智慧互動終端、機器人、語音問答、衛教腳本、現場流程引導 | 降低現場說明負擔，提高長者理解與參與 |
| 照護層 | 紅黃綠燈分流、健服中心課程、復健、營養、家醫、老年醫學、骨科、院外門診部、長照資源 | 讓篩檢結果進入可追蹤的照護行動 |

### 2. AI 模型的價值來自標準答案與驗證設計

影像模組可提供低負擔輸入，模型價值則由清楚的標準答案與驗證流程支撐。第一年可先建立資料字典與 validation workbook，明確記錄每位個案的 reference-standard label、量測條件、設備設定、場域來源與追蹤結果。

建議第一年驗證欄位：

| 欄位類別 | 建議內容 |
| --- | --- |
| Reference label | BIA / ASMI、握力、小腿圍、SARC-F、SPPB、步速、跌倒史、疼痛量表、共病、用藥 |
| Function signal | STS5、TUG、步態、坐站速度、平衡、轉身、步幅、步速 |
| Population signal | 年齡、性別、場域來源、社區 / 健康中心 / LTC / 醫院門診 source label |
| Device signal | camera setup、距離、角度、解析度、光線、測試場地、標準椅、操作人員 |
| Model evidence | AUC、敏感度、特異度、校準分析、外部驗證、資料缺漏率、TFDA / IRB 狀態 |

### 3. 現場安全是服務品質的一部分

TUG、五次坐立與步態測試涉及起身、轉身、行走與坐下。高齡者在測試時需要清楚指引、標準場地、人員觀察與中止條件。這些設計讓測試流程具備安全、可重複與可審查的品質。

建議寫入 SOP 的設計控制：

- 標準椅、標準距離、地面標線與攝影位置。
- 測試前確認長者理解流程，必要時提供台語或家屬 / 工作人員協助。
- 人員站位、扶持責任、測試中止條件與跌倒應變流程。
- 影像模組輸出作為篩檢輔助與風險提示，臨床判讀與照護導流由人員 / 臨床團隊承接。
- 年度 safety KPI 包含測試完成率、中止率、人員在場率與事件回報。

### 4. 健康艙與機器人分工形成可維護架構

健康艙、智慧互動終端與雲端平台各自承擔最適合的角色。健康艙負責穩定量測與資料匯流；機器人 / 互動終端負責溝通、衛教、導覽與現場互動；雲端平台負責資料整合、報告、Dashboard、LINE / APP 與 HIS/FHIR-ready mapping。

```text
健康艙 / station
-> 基礎生理量測 + BIA / 身高體重 / 血壓血糖血脂 / 問卷 / 外部資料匯入
-> 雲端平台 / Dashboard / QR report
-> 紅黃綠燈分流 + 家醫科 / 復健 / 營養 / 健促班導流

智慧互動終端 / 機器人
-> 流程說明 + 衛教 + 導覽 + 安全提醒 + 互動問答
-> LINE / QR / 報告帶走 + 後續追蹤入口
```

這個分工讓計畫同時具備採購彈性、維護可行性、場域安全與科技展示效果。

### 5. LINE 作為低門檻追蹤入口，APP 作為進階能力

會議中 Ken 提到台灣與泰國許多社區健康管理場景使用 LINE，核心原因是高齡者學習成本低、工作人員推廣容易、訊息與衛教到達率高。建議第一版以 LINE 作為低門檻入口，承擔提醒、衛教、問卷、回診或課程通知；APP / Web App 保留給影像量測、遊戲化任務、感測器整合與較嚴謹身分驗證場景。

## 主要討論內容

### 深耕計畫主體與原始設計

會議確認華山場域主軸為「高齡者 AI 步態與肌少症風險篩檢暨閉環整合照護導流計畫」。草案設定為三年期，116-118 年，每年約新臺幣 17,500,000 元。技術組負責手機 / 平板影像量測 STS5、TUG 與步態，建立肌少症與跌倒風險 AI 預測模型；護理 / 照護端負責 COM-B 個人化動機回饋、APP 或 LINE 居家追蹤、衛教與紅黃綠燈分流。

本次會議的 v2 敘事把智慧互動終端、機器人、健康艙、影像模組、LINE / APP 與臨床標準答案串成一條服務系統。計畫書可以用「健康艙量測、機器人互動、雲端整合、臨床導流」作為清楚架構，讓設備功能、KPI、收案、資料治理與採購邏輯一致。

### 機器人定位

機器人適合作為高齡者友善的現場互動介面。它可提供語音與螢幕引導、健康服務中心導覽、流程說明、衛教播放、簡單 Q&A、QR / LINE 引導與安全提醒。CV 影像模組可放在機器人或場域設備上，作為選配或後續驗證能力。

建議 proposal 句型：

```text
智慧互動終端 / 機器人提供流程引導、衛教、導覽、安全提醒與現場互動輔助；影像篩檢模組作為選配或後續驗證模組，於完成設備、場域、人員安全與模型效度確認後納入擴充。
```

### 既有影像模組與效度資料

Ken 口頭說明，過去已有衰弱篩檢、跌倒風險評估與肌少症量測的影像模組案例，曾在照護場域與醫院健康檢查場景使用。此資訊可作為 feasibility signal，後續計畫書可將它轉化為資料需求與驗證設計。

建議向合作方取得：

- 訓練資料來源、樣本數、陽性 / 陰性比例。
- 年齡、性別、疾病族群與場域來源。
- 模型指標、外部驗證結果與校準方式。
- 測試條件、設備規格、camera setup 與操作流程。
- TFDA、IRB、資安與資料處理狀態。

### 收案與模型驗證

江老師指出社區整篩可提供大量場域資料，模型驗證則需要同時納入陽性與陰性個案。建議第一年即建立陽性個案來源，例如養護中心、長照據點、復健科、老年醫學、心衰或其他高風險族群，並與社區健康族群形成可判別的 validation cohort。

收案表建議欄位：

| 類別 | 欄位 |
| --- | --- |
| 分層 | 陽性 / 陰性、年齡層、性別、場域來源、族群來源 |
| 標準答案 | BIA / ASMI、握力、小腿圍、SARC-F、SPPB、步速、跌倒史 |
| 影像輸入 | STS5、TUG、步態、camera setup、測試距離、測試場地 |
| 治理 | 同意流程、IRB / QI 判定、資料保存、去識別化、資安 |
| 輸出 | AUC、敏感度、特異度、校準、外部驗證、年度報告 |

### 健康艙用途

健康艙可成為高齡者肌肉健康計畫的量測與資料整合 anchor。它可承擔身高、體重、BMI、血壓、脈搏、血糖、血脂、BIA 或外部匯入資料，並與握力、小腿圍、SARC-F、SPPB、STS5 / TUG、跌倒史、疼痛與問卷資料形成整合報告。

建議 proposal 句型：

```text
健康艙整合基本人口學、生理量測、肌少症相關量測資料、互動問卷、衛教回饋、QR 報告與後續 HIS/FHIR-ready 資料流，支援紅黃綠燈分流、家醫科或健康促進課程導流，以及年度 KPI evidence。
```

### 授權、採購與合作治理

若後續將語音問答、AI 互動或影像模組放入慧誠智醫設備，授權、採購、維護與商業條款可由吳老師與合作方另行協調。計畫書可先使用功能需求、驗證需求、資料治理與採購規格語言，保留多供應商與採購合規彈性。

## 建議更新後的計畫敘事

本計畫以社區高齡者肌少症與跌倒風險篩檢為入口，建立「量測、分流、衛教、導流、追蹤」的閉環照護流程。AI 影像模組以 STS5、TUG 與步態為低負擔功能性指標，並以握力、BIA、SARC-F、SPPB、小腿圍、跌倒史與臨床資料建立標準答案與外部驗證。智慧互動終端與機器人承擔流程引導、衛教、導覽、互動問答與使用者回饋；影像量測依場域條件與採購結果作為選配功能。健康艙 / station 作為 vital signs、BIA、基本健康資料與問卷蒐集節點，透過雲端平台、FHIR / HIS-ready mapping、個管 Dashboard 與 LINE / APP 追蹤，支援紅黃綠燈分流與聯醫多專業照護導流。

# Open Questions

## Workflow Questions

1. What is the current patient flow from check-in to physician entry?
2. Which questions are repeated most often?
3. Which information can be safely collected before the physician enters?
4. Which topics must remain physician-led?
5. Should the first realistic version be self-filled, nurse-assisted, or mixed?

## Output Questions

1. What summary format would the physician actually read?
2. Which fields are useful and which are noise?
3. Should the summary include missing information, review flags, or both?
4. Would a one-page summary be enough?

## Adoption Questions

1. Who benefits most from the system: patient, nurse, physician, or clinic flow?
2. What would make staff reject it?
3. What would make clinicians trust it?
4. What is the smallest useful next artifact?

## Safety Questions

1. What wording is acceptable for red-flag observations?
2. What privacy model would be needed before real patient data?
3. What consent language would be required?
4. What failure reporting process would be needed in a pilot?

## Decision Questions

1. Should the project continue after the physician meeting?
2. If yes, is the next step a revised question tree, summary mockup, or assisted workflow test?
3. If no, what did the meeting teach about the wrong assumption?
